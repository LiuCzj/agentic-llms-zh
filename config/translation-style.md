# 翻译风格约定

## 总原则

**意译优先，拒绝逐字直译。** 目标是让中文读者读到通顺、专业、符合中文技术写作习惯的句子，而不是英文语序的堆砌。

## 具体规则

1. **句子重构**：英文长句拆成中文短句；被动语态转主动；避免「的的不休」。
2. **术语一致**：严格遵循 `glossary.md`；同一术语全书统一。
3. **首次对照**：未在术语表中的专业术语，首次出现写作「中文（English）」，之后只用中文。
4. **保留专有名词**：模型名、产品名、论文标题、人名、机构名保持原文。
5. **锁定不可译内容**：公式、代码、URL、DOI、引用编号、交叉引用标签一律原样保留。
6. **代码块**：`minted` / `lstlisting` 环境内——
   - **代码本身不改动**：变量名、函数名、类名、语法、字符串字面量、缩进一律保留原样。
   - **英文注释译为中文**：`#`、`//`、`/* */`、docstring 等注释内容翻译，注释符号与缩进层级保持不变。
   - 判定标准：注释是「给人看的说明」→ 翻译；字符串字面量是「给程序用的数据」→ 不翻译。

7. **交叉引用与超链接**：`\ref{}`、`\cite{}`、`\label{}`、`\href{}`、`\url{}` 的参数**一个字符都不能改**。
8. **数学模式**：`$...$`、`\[...\]`、`equation` 等环境内的内容**完全不动**。
9. **语气**：保持教材的讲解语气，使用「我们」「你将学会」等，与原文人称一致。
10. **标点**：使用中文全角标点；公式、代码、英文专名内部保持半角。
11. **列表与标题**：标题层级、编号、列表结构原样保留，只译文字。
12. **强调标记**：`{\em ...}`、`\textbf{}` 等保留，只译内部文字。

## 环境与命令处理

| LaTeX 结构 | 处理方式 |
|---|---|
| 正文散文 | 翻译 |
| `\section{}` / `\subsection{}` 等标题 | 翻译文字，保留命令 |
| `\caption{}` | 翻译 |
| `\begin{learningbox}` 内文字 | 翻译 |
| `\begin{example}` 内文字 | 翻译 |
| `\footnote{}` | 翻译 |
| `\begin{minted}` / `lstlisting` | 不动 |
| `\begin{equation}` 等 | 不动 |
| `\includegraphics{...}` 路径 | 不动 |
| `\input figures/xxx` | 若为 tikz 图，翻译其中的 `\node{...}` 文字 |
| `\ref{}` / `\cite{}` / `\label{}` | 不动 |
| `\url{}` / `\href{}{}` | URL 不动，链接文字翻译 |
| 注释 `% ...` | 默认不动 |
